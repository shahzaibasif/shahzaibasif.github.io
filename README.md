## Local Development

Because this is a static portfolio website, you can run it locally with any lightweight web server.

### Option 1: Python HTTP server

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

### Option 2: Open directly

You can also open `index.html` directly in a browser for quick previewing.
